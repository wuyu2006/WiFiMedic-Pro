应用信息

关于

一个本地运行的中文网络诊断工具。

WiFiMedic 网络医生

Android 伴侣版 · 1.0.0

本地工具

能做什么

  • 读取当前网络类型、IP、网关与 DNS。
  • 检测厂商节点、公共 DNS、TCP 443 与 HTTP 访问。
  • 执行 8 项网络体检，并给出评分与阶段结果。
  • 查看 Wi-Fi 信号、频段、链路速率与周边网络。
  • 执行一次轻量下载测速，了解当前带宽。

平台限制

  • Android 不开放已保存 Wi-Fi 密码给普通应用。
  • 系统代理、DNS 修复与网卡跃点调整需要系统权限，本版不提供。
  • 测速结果受测速节点、运营商与 Wi-Fi 环境影响。

隐私说明

所有检测在本机完成，不上传网络信息。体检结果与设置仅保存在本机 WebView 存储中。

Windows 版提供完整的 Wi-Fi 密码核对、系统修复与更深入的网络体检。
