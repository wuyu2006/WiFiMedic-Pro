## 二、Windows 便携版

### 1. 运行方式

1. 双击 `WiFiMedic-Pro-1.0.0-Portable.exe`。
2. 首次运行如弹出 Windows SmartScreen：
   - 点击“更多信息”；
   - 点击“仍要运行”。
3. 建议右键选择“以管理员身份运行”，以便使用网卡、DNS、Winsock 等修复功能；普通权限也可以完成查看、体检、连通性测试和测速。
4. 在普通权限下点击“管理员执行 / 管理员重启”时，Windows 会弹出 UAC 授权窗口，请点击“是”。如果没有弹窗，请关闭应用后右键 EXE，选择“以管理员身份运行”。
5. 如果界面字体偏小，可点击标题栏右侧的齿轮按钮（或按 `Ctrl+,`）直接定位到偏好设置，在「界面字号」中选择“舒适”或“特大”，调整后会保存。

系统要求：Windows 10 / 11，64 位。  
程序不会自动安装服务、驱动或开机启动项；退出后不常驻。

### 2. 主要功能

- **健康总览**：自动识别当前主用通道（有线 / 无线），用一屏展示健康评分、链路、IP、网关、DNS、代理、延迟、丢包和待处理问题。实时曲线、厂商节点矩阵和无线详情分别放在「速度与稳定」「连通性测试」「Wi-Fi 管理」页面，避免首页重复堆叠和整页滚动。
- **全面体检**：14 个阶段，覆盖系统环境、路由、网卡、IP/DHCP、网关、DNS、厂商节点 Ping、TCP 443、HTTP、Wi-Fi 链路、安全、代理、MTU 与路由追踪。完成后生成中文报告与修复建议。
- **连通性测试**：一键 Ping 网关、阿里云、腾讯云、百度、阿里、腾讯、京东、哔哩哔哩、苹果等节点。界面中的“全部已启用节点”必须全部可达才显示通过；Google 等国际节点默认关闭，手动开启后会参与判定。
- **Wi-Fi 管理**：
  - 查看当前无线连接、信号、频段、信道、速率和安全类型；
  - 查看当前无线网络的已保存密码，支持显示 / 隐藏、复制、核对；
  - 支持读取 Windows 已保存的无线配置文件；
  - 无无线网卡时自动降级为紧凑布局，并把密码卡提前显示。
- **速度与稳定**：下载 / 上传测速、延迟、抖动、丢包、缓冲膨胀和实时曲线。
- **修复工具**：刷新 DNS、重建 ARP、启动 WLAN、重启网卡 / WLAN、重新获取 IP、切换公共 DNS、关闭代理等；危险操作会二次确认。
- **报告中心**：自动保存最近 30 份报告，可导出 HTML / JSON / TXT，支持浅色 / 深色主题。
- **界面字号**：点击标题栏齿轮或按 `Ctrl+,`，在「偏好设置」切换标准（100%）/ 舒适（120%）/ 特大（135%）。默认使用舒适比例，适合 1080p 屏幕；字号设置会保存在本机。
- **隐私**：检测在本机完成，不上传网络配置或报告；仅在测试目标时访问对应公开网络节点。

### 3. Wi-Fi 密码功能说明

- **仅对无线连接生效**：当前版本只支持查看无线网络的已保存密码，不支持有线网络密码。
- 需要 Windows 的 **WLAN AutoConfig（WlanSvc）** 服务正常运行；如果服务停止或没有无线网卡，会显示“未检测到无线网卡 / 无线能力受限”，密码卡仍会显示但功能不可用。
- 读取的是当前 Windows 用户已保存的无线配置文件密码；如果系统策略、企业证书或第三方管理软件限制，可能无法读取。
- 密码只在本机显示和复制，不会上传。
- 请在合法授权范围内使用，不要查看或传播不属于你的网络密码。

## 三、Android 伴侣版

### 1. 安装

1. 将 `WiFiMedic-Android-1.0.0.apk` 传到 Android 手机。
2. 在文件管理器中点击安装；如提示限制，请在系统设置中允许该来源“安装未知应用”。
3. 首次打开后，按提示授予“附近设备”或“位置”权限，并打开系统定位服务，否则可能无法读取 Wi-Fi 名称、BSSID 或扫描周边网络。

系统要求：Android 6.0 及以上（最低 API 23，目标 API 34）。

### 2. 功能范围

- **总览**：网络类型、连接状态、本机 IP、网关、DNS、链路信息。
- **8 项体检**：连接、地址、网关、DNS、TCP、HTTP、Wi-Fi 信息和安全建议。
- **连通性**：测试网关与国内厂商节点，显示延迟和通过状态。
- **Wi-Fi**：当前连接、信号、频段、信道、速率、安全类型、周边扫描。
- **速度**：轻量下载测速。
- **关于**：版本、隐私说明和平台限制。

### 3. Android 平台限制（重要）

- **普通 Android 应用无法读取系统保存的 Wi-Fi 密码**。读取密码通常需要 root、系统级权限或设备厂商私有接口；本 APK 不提供该能力，也不会尝试提权。
- 如需查看当前 Wi-Fi 密码，可在系统 Wi-Fi 设置中点击当前网络，使用系统提供的“分享”二维码。
- Android 版是伴侣工具，**不提供** Windows 系统修复、重启网卡、Winsock 重置等能力。
- 部分厂商系统会限制后台扫描或对扫描结果脱敏；如果列表为空，请检查权限、定位服务和系统省电策略。
- APK 使用本地自签名发布证书，不是应用商店版本；升级安装时请保持同一签名。

## 四、构建与源码

### Windows

需要 Node.js 18+：

```powershell
cd WiFiMedic
npm install
npm start        # 开发运行
npm run dist     # 生成 release\WiFiMedic-Pro-1.0.0-Portable.exe
```

若 Electron 下载慢，可设置镜像：

```powershell
$env:ELECTRON_MIRROR = 'https://npmmirror.com/mirrors/electron/'
$env:ELECTRON_BUILDER_BINARIES_MIRROR = 'https://npmmirror.com/mirrors/electron-builder-binaries/'
npm run dist
```

构建产物为 `release\WiFiMedic-Pro-1.0.0-Portable.exe`。程序未使用商业代码签名证书，Windows 可能显示“未知发布者”。

### Android

源码位于 `WiFiMedic\android`，构建脚本为 `android\build.ps1`，使用 JDK 17、Android build-tools 34 和 `android-34` 平台，不依赖 Gradle。

```powershell
# 建议在纯 ASCII 路径下构建；aapt2 无法直接处理中文路径
# 可创建指向项目根目录的 junction 后执行：
android\build.ps1
```

签名配置：`android\keystore\wifimedic-release.jks`，alias `wifimedic`。该密钥仅用于本项目的本地更新签名，请妥善保管。  
输出：`release\WiFiMedic-Android-1.0.0.apk`。

## 五、隐私与数据位置

- Windows 数据目录：`%APPDATA%\wifimedic-pro`（报告、设置、修复日志）。
- Android 数据：应用私有 WebView 存储，卸载应用后清除。
- 不上传报告、密码或网络配置；没有遥测和广告 SDK。
- 体检、Ping、DNS、HTTP、TCP 和测速会向对应目标发起网络请求；这是检测功能所必需的。
- 测速会使用公开测速节点；结果受运营商、时段、服务器和本机负载影响。

## 六、已知限制

- 本项目开发/测试机没有无线网卡，且 `WlanSvc` 曾停止，因此 Windows 的真实 Wi-Fi 密码读取和真实无线链路只验证了降级路径、解析逻辑和布局；请在有无线网卡的机器上复核密码卡。
- Android APK 已完成构建、签名和 `apksigner` / `aapt2` 静态校验，但当前构建环境没有 Android 真机或模拟器，尚未做真机运行验证。
- Google 等国际节点在部分网络不可达；默认不启用，可在连通性页面手动开启。开启后按“全部已启用节点可达”规则判定。
- Windows 便携版未签名，首次运行可能触发 SmartScreen。
- 本工具提供网络诊断和常见修复建议，不替代运营商、路由器厂商或专业网络运维。

## 七、快速开始

**Windows**：双击 EXE → 在健康总览点击“开始全面体检” → 在连通性页面点击“一键连通测试” → 在 Wi-Fi 管理查看无线密码 → 在报告中心导出报告；界面大小可随时点击标题栏齿轮或按 `Ctrl+,` 调整。

**Android**：安装 APK → 授予附近设备 / 位置权限 → 总览页查看网络 → 点击“开始体检” → 在 Wi-Fi 页扫描周边网络 → 在关于页查看平台限制。
